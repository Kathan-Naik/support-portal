Every call carries two labels

A pill is what the agent said. A word with a dot is what the booking system accepted: periwinkle when done, apricot when still owed. A row where they disagree turns apricot.

Outcome, said by the agent

booked
Agent confirmed a new appointment to the caller.
rescheduled
Old slot released, new slot confirmed.
cancelled
Appointment released.
resolved
Question answered, no appointment change.
transferred
Handed to a human at the front desk.
abandoned
Caller hung up before an outcome.

Write, accepted by the booking system

written 201
A 2xx from booking-sync, with an external id.
failed 401
Every retry failed and the write was dead-lettered.
no write
The call never needed one.
duplicate
Same telephony id ingested twice. Hidden by default.
